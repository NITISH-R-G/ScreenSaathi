# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/),
kept short rather than reproduced in full legalese:

- Be respectful. Disagree about code, not about people.
- No harassment, discrimination, or personal attacks, in issues, PRs, or
  commit discussion.
- Assume good faith on first contact; escalate to maintainers if it isn't
  reciprocated.

Reports of unacceptable behavior can be raised by opening an issue tagged
`conduct` or, if it needs to stay private, by contacting the repository owner
directly through their GitHub profile.

Maintainers may remove comments, commits, code, issues, or other contributions
that don't align with this Code of Conduct, and may temporarily or permanently
ban anyone for behavior they deem inappropriate, threatening, or harmful.
